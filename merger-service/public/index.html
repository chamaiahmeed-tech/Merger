🎬 دمج الفيديوهات

ارفع مقاطعك أو أضف روابط مباشرة، رتّبها بالترتيب الذي تريد، واحصل على فيديو MP4 واحد عالي الجودة.

1) أضف المصادر

اسحب ملفات الفيديو هنا أو انقر للاختيار من جهازك mp4 · mov · webm · mkv · avi · m4v · mpg · 3gp

2) رتّب المصادر (ترتيب الدمج)

    لم تُضف أي مصادر بعد — يلزم مقطعان على الأقل.

    يمكنك السحب والإفلات أو استخدام أزرار ↑↓ لإعادة الترتيب — الترقيم هو ترتيب الدمج.

    📚 توثيق API (قابل للطي)
    MethodEndpointالوظيفة
    POST/api/jobsإنشاء مهمة دمج
    POST/api/upload?job=&seq=&chunk=رفع أجزاء الملفات (ثنائي ≤ 4MB)
    POST/api/jobs/{id}/processتنفيذ الدمج كاملًا → رابط الناتج
    GET/api/jobs/{id}الحالة + التقدم (0–100) + الرابط عند الاكتمال
    GET/api/jobs/{id}/videoبث الناتج (يدعم Range و ?download=1)
    DELETE/api/jobs/{id}حذف فوري شامل
    GET/api/configالحدود العامة + version
    GET/api/cronحذف المهام المنتهية
